题目原文

平行铝板 M、金属板 N 中心有小孔 P；P 右侧有与 N 板相切于 P、半径 R 的圆形匀强磁场（垂直纸面向外），上方为水平荧光屏。紫外线照射 M 发射电子，M、N 间电压为 U₀ 时恰好无电子能从小孔飞出。保持电压大小、反向电场后，从 P 垂直 N 板射入、动能最大的电子，经磁场偏转后刚好垂直打在荧光屏上。求电子最大初速度 v₀、磁感应强度 B，以及电子打到荧光屏上距 N 板的最远距离。

已偏离题目条件，读数仅供参考

要点

恰好无电子出射：最大初动能 ½mv₀² = eU₀ → v₀ = √(2eU₀/m)。
反向加速后出孔速度 v₁ = √2·v₀；垂直入射时转 90°、r = R，
ev₁B = mv₁²/R → B = (2/R)√(mU₀/e)。
半径 R 的圆磁场会把从 P 进入的电子**准直成平行**（都竖直向上），
入射角 45° 的那束落点最远：x = R + R·cos45° = (2+√2)R/2。
