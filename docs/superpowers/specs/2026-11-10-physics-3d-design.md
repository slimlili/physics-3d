# 高中物理三维演示工具（自用版）设计说明

日期：2026-11-10
状态：已确认

## 为什么做

备课时把一道题变成能拖视角的三维过程，比静态图直观得多。已经验证可行：现有 5 个 three.js 演示（电场圆弧轨道、电场斜抛、静电离子阱、磁场圆周、磁场螺旋），学生看轨迹和矢量比看图快。

痛点是每个演示都从零写：重复实现控制器、视觉、答案面板，风格和操作还不统一。这套工具要解决的就是这个重复劳动。

## 谁用

只有本人（物理老师）。使用场景：
- 备课：把明天要讲的题做成一版
- 课堂：投屏，边讲边拖视角、调参数
- 课后：把 HTML 文件发给学生自己看

## 核心交付：一套每次照做的方法

这套东西的主体不是某一批演示文件，而是一份**流程**。以后你把题发过来，我按它走，不靠临场发挥；流程本身可以改、可以补，越用越顺。演示文件只是流程的产物。

流程六步：

1. **复述**：先用两三句话说出我读到的题——什么场、什么粒子、几何关系、要求什么。你扫一眼就能发现我有没有读错。
2. **判模型**：对照"题型 → 模型"判定表，落到具体模板；判不了就明说卡在哪，不硬套。
3. **定几何**：坐标系、正方向、场景比例，以及题目给定值与画面显示值的关系。
4. **生成**：套底座 + 模板填参数；模板不够时做"最接近模板 + 增量"，并把增量沉淀回库里。
5. **自检**：物理量自动比对（模板自带解析解）、渲染检查（截图、报错、穿模）、交互检查（暂停、速度、开关）。
6. **交付**：文件路径 + 三句话操作说明 + 本题的物理要点（哪一步是题眼）。

模板库、共用底座、生成与自检脚本都是这套流程的零件，不是目的。

## 目标

1. 拿到一道磁场为主的运动题（文字、照片、PDF、docx 均可），**一次往返内**产出可用的演示
2. 所有演示操作一致：拖视角、滚轮缩放、空格暂停、四档播放速度、轨迹/矢量开关、答案面板
3. **断网可用**（three.js 本地化，不依赖 CDN）
4. 生成后自检：无 JS 报错、关键元素在画面内、方向与题目一致

## 非目标

- 不做供同事或学生自助提交的网站
- 不做自动判题、评分、批改
- 不做题库管理、账号、服务器部署
- 不追求覆盖全部高中物理：电学实验、电路、热学、光学不在范围内

## 反目标（做到了也算失败）

- 演示的物理或几何是错的——错误的演示比没有演示更糟
- 每个演示的按钮位置和手感都不一样，上课时还要重新找
- 生成一个演示要来回改五轮
- 打开需要联网

## 约束

- 技术栈固定：three.js r169 + 原生 JS，无构建步骤、无框架
- 产物是本地 HTML，双击即开
- 中文界面
- 风格以现有 5 个演示为基准（深色背景、青绿主色、右下角卡片面板）

## 交付形态（评审后定）

- 每份演示是**一个单文件 HTML**，three.js 内联（importmap 指向 data: URL），约 2MB
- 原因：本地页面用相对路径加载 JS 会被浏览器的安全策略拦掉；只有内联才能同时做到「双击即开 + 断网可用 + 能直接发给别人」
- 目标设备：**电脑浏览器为主**（Chrome / Safari / Edge）；手机上能打开可看，但不作为主要适配目标
- 工具目录只保存模板和 lib 源文件；生成时由脚本把 lib 内联，产出单文件

## 已经定下的选择（你定的）

- 自用版，不做公开网站
- 磁场优先：接下来两三周以磁场题为主
- 用 three.js 做三维渲染
- 生成流程由 Claude Code 执行：每次把题发给我，我按固定流程产出文件（交付物 = 模板库 + 生成脚本 + 自检脚本 + 技能文档），不做独立本地应用

## 数据与读数（评审后补定）

- **读数用题目的真实数值**：题目给了 B、v、q/m（或可由电量、质量推出）时，页面上显示真实的 r、T、t，与解析式对得上；场景几何按比例缩放，不影响读数
- 题目只给符号不给数值时，读数显示解析式（如 `r = mv/qB`）和当前参数下的比例，不编造具体数字
- 每个模板的滑块范围按题目量级给，不用无量纲玩具数

## 答案面板与题目原文

- 答案固定对应**题目给定条件**；课堂上拖动参数后，答案顶部出现提示「已偏离题目条件，读数仅供参考」，避免答案与画面打架
- 题目原文与配图以可折叠卡片形式放进页面（默认收起），学生课后单独打开也知道这题在问什么

## 自检（物理正确性）

- 每个模板带一份解析解计算函数（输入题目参数 → 期望的 r、T、t、N 等）
- 生成时把期望值写进页面（不显示），自检脚本用 headless Chrome 读取页面读数 DOM，与解析值比对，超出容差即报错
- 渲染层另查：console 无错、关键元素可见、无穿模

## 旧演示的处置

- 一期**不迁移**现有 5 个演示，只保证新生成的演示符合新标准
- 哪些旧演示课上还要用、且需要断网，再逐个迁移；迁移时按新底座重写，不做兼容层

### 判定表（流程第 2 步用）

| 题目特征 | 归到 |
|---|---|
| 只有磁场，粒子垂直射入，无边界 | T1 圆周运动 |
| 有直线边界，"恰好射出""求弦长/时间" | T2 直线边界 |
| 速度与 B 斜交，出现"螺距" | T3 螺旋 |
| 同时有 E 和 B，要求"直线通过""选择速度" | T4 速度选择器 |
| 圆形边界、临界、多段轨迹 | 二期模板；当前：最接近模板 + 增量，或明说做不了 |

### 共用底座

把现有演示里重复的部分抽成一份底座模板，新演示都从它长出来：

- 视觉 token：深色背景、青绿主色、卡片面板、等宽数字
- 控制器：播放速度四档（¼× ½× 1× 2×）、暂停/重播、开关组
- 答案面板：默认收起，点「看答案」展开
- 现成封装：矢量箭头、文字标签、轨迹线、光晕粒子
- 固定读数区：显示本题的关键量（半径、周期、时间等）

### 模板（一期：磁场优先）

| 编号 | 模板 | 参数 | 演示要点 |
|---|---|---|---|
| T1 | 无边界匀强磁场·圆周运动 | 入射方向、速率、B、电荷正负 | 轨迹圆、圆心、半径、周期、偏转角 |
| T2 | 直线边界磁场 | 边界位置、入射角、速率、B | 进出边界、弦长、圆心角、在磁场中运动的时间 |
| T3 | 磁场中的螺旋运动 | v 与 B 的夹角 θ、B、速率 | 螺距、半径、周期；θ→0 退化为圆周 |
| T4 | 复合场·速度选择器 | E/B 比、速率、电荷 | 直线通过或偏转，能看出筛选条件 v=E/B |

二期（先说好会做，但不在第一批）：圆形边界磁场·临界问题、回旋加速器、多段轨迹拼接。

### 验收标准

- 打开即动，3 秒内能看懂在讲什么
- console 无错误
- 画面上的读数与解析式一致（至少人工核对一次）
- 断网可以打开
- 操作与其它演示完全一致

## 留给实现时定的

- 每个模板具体给哪些滑块、默认值、读数项
- 标签与箭头的具体排版
- 是否给演示加分步模式（按步骤停住讲解）
- 演示文件命名规则

## 风险

- **读题出错**：题目配图模糊、几何关系隐含，可能导致模型判错。缓解：生成前先用一两句话复述"我判断这是 X，几何是 Y"，让你扫一眼。
- **模板不够**：遇到复合、多段、临界题，模板可能套不上。缓解：明确告知，不硬套；必要时为单题定制。
